Stock Market Analytics Dashboard using Power BI 📊

An interactive Power BI dashboard designed to analyze and visualize stock market data of Reliance Industries Ltd. The dashboard provides insights into stock price movements, trading volume, and historical market trends using data visualization and analytics.

**Tools Used:** Microsoft Power BI, Power Query, Data Visualization

**Key Features:**

* Stock price trend analysis
* High, Low, Open, and Close price visualization
* Trading volume analysis
* Interactive date slicer
* Historical stock market performance tracking
* Dynamic and interactive dashboard

This project helps users understand stock market trends and make data-driven decisions through interactive visualizations.
